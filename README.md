# K-Means Clustering Streamlit App

This is a simple Streamlit dashboard to perform K-Means clustering on your CSV dataset.

How to run:

1. Create and activate a Python environment (recommended).
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit app:

```bash
streamlit run app.py
```

Features:

- Upload a CSV dataset
- Select numeric features to use for clustering
- Choose number of clusters (K)
- View clustered results and counts
- View 2D scatter plot (direct features or PCA projection)
- Download clustered CSV results
